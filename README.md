# MaaGeikomi

基于 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 的四合一护肝助手。

## 支持的游戏

本项目支持 XXL 猛汉特区（XXL WOOFIA / XXL 猛漢町）、东京放课后召唤师（Housamo）、Live A Hero、神绊的导师（Crave Saga）。

## 免责声明

本项目是图像识别加模拟输入的自动化工具，不修改游戏本体、不读写游戏内存、不篡改网络数据。自动化行为仍可能违反游戏的用户协议。请自行评估风险，账号后果自负。

请勿在游戏官方渠道（官方社区、官方账号、玩家群等）提及或推广本项目。
